# Hangman Game

This project was created by Ellena Tzavelas using [Create React App](https://github.com/facebook/create-react-app).

## About

Your typical game of hangman just got more interesting! A random word or phrase will be generated from [Wikipedia's random article generator](https://www.mediawiki.org/wiki/API:Random) which the player will have to guess. The player will only need to guess characters from the English alphabet, all other characters will be shown to the player. Once the player has successfully guessed the word or phrase, they will prompted to visit the article with that title on Wikipedia.

There are 3 difficulty options available: 'Easy' (allows 10 wrong letters), 'Hard' (allows 5 wrong letters) or 'None' (allows infinite wrong letters). The player can also choose at any point to 'Give Up' which will reveal the word or phrase, or to generate a 'New' word or phrase.

The design of the project was influenced by the UI of the 2016 Atlus Game Persona 5.
